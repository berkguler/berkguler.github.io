Overview

Drilling a hole into a curved surface at a desired angle is error-prone when done by hand: the drill is hard to align, the task is inherently unstable, and it can cause injury and fatigue. Fully automating it is often impractical too, because parts arriving at an assembly line come in many shapes and drill locations are not always accessible to a pre-planned path. We developed a 6-DoF adaptive admittance controller on a KUKA LBR iiwa 7 cobot so that an operator can move a robot-mounted drill with one hand. The admittance damping adapts to the task phase, haptic guidance aligns the drill and then constrains motion to the drilling axis, and an AR interface on a Microsoft HoloLens provides visual guidance.

Key results

  • 26%shorter task completion time with haptic guidance
  • 16%less human effort
  • 27%lower forearm muscle activation (sEMG)

These numbers come from a first experiment with three naive participants. In a second experiment, three experienced industrial workers rated the system as easy to use, safe, and helpful for the drilling task.

My contributions

  • Developed an admittance controller in C++ using the Fast Robot Interface (FRI) of the KUKA iiwa cobot.
  • Developed the mixed-reality interface in C# for Microsoft HoloLens with Unity and the Mixed Reality Toolkit (MRTK).
  • Implemented a Kalman filter to track the 6-DoF motion of the HoloLens and the workpiece from AprilTag fiducial markers.
  • Built a 3D mesh model of the workpiece with a depth camera (Microsoft Kinect).
  • Set up TCP communication between the robot and the HoloLens.
