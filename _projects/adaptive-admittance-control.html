Overview

We propose a supervised learning approach based on an artificial neural network (ANN) for real-time classification of subtasks in a physical human-robot interaction (pHRI) task that involves contact with a stiff environment. The task is split into three subtasks: Idle, Driving, and Contact. Based on this classification, the parameters of an admittance controller that regulates the interaction between human and robot are adjusted in real time, making the robot more transparent to the operator (less resistant) during Driving and more stable during Contact. The Idle phase is used to detect the start of the task.

My contributions

  • Developed the control architecture that regulates human-robot physical interaction through an admittance controller on the KUKA iiwa cobot.
  • Performed a linear time-varying stability analysis of the pHRI system.
  • Developed the deep-learning subtask classifier in Python with TensorFlow.
  • Developed the methods that adapt the admittance parameters from the classifier's output.
  • Built a C# GUI to read and record data from ATI force/torque sensors.
  • Designed the pHRI experiments, collected the data, and performed the statistical analysis.
