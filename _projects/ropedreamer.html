Overview

Data-driven rope models often predict well for a few steps and then drift: segments stretch, pass through each other, or lose loops that were there. RopeDreamer combines two ideas to keep long rollouts physically plausible. First, the rope is represented as a kinematic chain, i.e. the position of the first segment plus relative rotations (unit quaternions) between consecutive links, so constant link length is built into the state. Second, dynamics are learned with a recurrent state-space model (RSSM) that rolls the state forward in a compact latent space, with separate decoders for reconstructing the current state and predicting the next one.

Key results

  • 40.5%lower position error at 50 prediction steps than the best baseline
  • 31%less inference time per step than the best baseline
  • 1Msimulated pick-and-place transitions for training and evaluation

RopeDreamer also preserves topology far better than graph-based baselines, measured by comparing Gauss codes of predicted and true rope configurations, which matters for downstream tasks like knot tying and untangling.
