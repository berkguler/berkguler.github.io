Overview

In real-time teleoperation, the operator should decide the rough motion while the robot handles fine adjustments, for example when the operator's view is occluded. We frame assisted teleoperation as tracking the operator's target pose as closely as possible subject to a set of constraints (static, self, dynamic and mutual collisions, and valid pre-grasp poses) that a simple state machine can switch on and off for task-specific assistance.

Solving this constrained optimization at every step is too slow for real-time control. Instead, the system samples robot configurations around the current state, predicts every active constraint cost with small neural networks for all samples in parallel, and selects the feasible configuration with the smallest distance to the operator's target. Once a pre-grasp becomes feasible near an object, the robot aligns itself to a valid grasp while the operator can still adjust it.

Key results

  • 1,024sampled configurations scored per step
  • ~25 Hzcommand rate with two Franka arms and VR control
  • 12 / 12successful table-clearing trials, vs. 10 / 12 without assistance

Less experienced operators appreciated that they only had to indicate roughly how to grasp an object and that collisions were handled for them, while experienced operators were bothered by the brief pauses before grasps while the system searched for a feasible pose.
